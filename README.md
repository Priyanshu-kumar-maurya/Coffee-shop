## 🌟 Key Features

- ☕ **Artisanal Coffee & Bakery Catalog:** Filter by Hot Brews, Iced & Nitro Cold Brews, Fresh French Pastries, and Organic Teas.
- 🔍 **Live Search Bar:** Instant search filtering by beverage name, roast levels, or flavor notes.
- 📅 **Interactive Table Reservation System:** Reserve cozy fireside tables or sunlit patio seating with instant confirmation ID.
- 🛒 **Full Shopping Cart Drawer:**
  - Slide-out Cart Drawer with LocalStorage persistence.
  - Quantity controls (`+` / `-`) and live subtotal calculation.
  - Discount promo code (e.g. `BREW15` for 15% OFF).
- 🎉 **Order Confirmation Flow:** Interactive brewing confirmation modal with receipt summary.
- 🎨 **Luxury Coffee House Aesthetics:** Warm obsidian mocha gradients, amber caramel highlights, and editorial typography.
- 📱 **100% Mobile & Desktop Responsive:** Pixel-perfect layout tailored for smartphones, tablets, laptops, and ultra-wide screens.
- ⚡ **Ultra Lightweight:** Pure Vanilla JavaScript, HTML5, and CSS3 with zero heavy dependencies.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Priyanshu-kumar-maurya/Coffee-shop.git
cd Coffee-shop
```

### 2. Run locally
Simply open `index.html` in any web browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

## 🛠️ Built With

- **HTML5:** Semantic markup, accessible forms, and clean modal dialogs.
- **CSS3:** Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphism backdrop filters, Keyframe animations.
- **Vanilla JavaScript (ES6+):** Cart state management, LocalStorage caching, dynamic menu filtering, and custom modals.
- **Fonts:** [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) & [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
